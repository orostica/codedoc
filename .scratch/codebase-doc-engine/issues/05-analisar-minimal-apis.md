# 05: Analisar fluxos com Minimal APIs

**What to build:** Analisar e documentar fluxos completos entre chamadas frontend e endpoints Minimal API com o mesmo rigor das verificações já disponíveis para Controllers.

**Blocked by:** 03: Detectar campo obrigatório ausente na requisição; 04: Comparar tipos de entrada e formatos de resposta.

**Status:** ready-for-agent

- [ ] Fixtures definem antecipadamente padrões suportados de rotas, grupos, parâmetros, corpos e respostas de Minimal APIs.
- [ ] Chamadas são ligadas aos endpoints por destino configurado, método e rota; endpoints e símbolos têm evidências rastreáveis.
- [ ] Verificações de campos obrigatórios, tipos de entrada e respostas funcionam nos casos resolvíveis, incluindo casos sem divergência.
- [ ] Handlers, convenções ou tipos não resolvidos aparecem na cobertura como lacunas.
- [ ] Um fluxo completo produz pacote e documento de exemplo validável; todos os casos esperados da matriz suportada passam.
