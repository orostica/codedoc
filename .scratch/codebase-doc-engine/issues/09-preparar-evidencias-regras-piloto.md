# 09: Preparar evidências das regras do piloto

**What to build:** Disponibilizar evidências suficientes para que um agente externo explique dados socioeconômicos, responsável financeiro e pré-validação da finalização da inscrição.

**Blocked by:** 07: Rastrear transformações nas rotas API do Next.js; 08: Tratar destinos ambíguos e obrigatoriedade condicional.

**Status:** ready-for-agent

- [ ] O recorte reúne pontos de entrada, símbolos, dependências diretas relevantes, validadores e fluxo entre frontend e backend.
- [ ] ViewModels homônimos são desambiguados por repositório, projeto e namespace quando demonstrável; ambiguidades restantes são lacunas.
- [ ] Mapeamentos AutoMapper e transformações só sustentam conclusões quando resolvidos; limitações de análise sintática são explícitas.
- [ ] Evidências distinguem validações de entrada, restrições de interface e regras aplicadas pelo servidor.
- [ ] Condições de composição familiar unipessoal, renda e benefícios são fornecidas para revisão, sem presumir equivalência entre frontend e backend.
- [ ] Fixtures representativas comprovam a seleção de evidências e suas lacunas; o pacote permite redigir uma explicação rastreável do recorte.
