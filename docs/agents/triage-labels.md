# Rótulos de triagem

| Papel | Rótulo | Significado |
| --- | --- | --- |
| needs-triage | needs-triage | Aguarda avaliação |
| needs-info | needs-info | Aguarda informações |
| ready-for-agent | ready-for-agent | Especificado para execução por agente |
| ready-for-human | ready-for-human | Requer implementação humana |
| wontfix | wontfix | Não será executado |

Usar esses valores na linha Status dos tickets locais.
claimed e resolved representam execução e conclusão,
respectivamente; não são rótulos de triagem.
