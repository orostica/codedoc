# Documentação de domínio

Layout de contexto único:
- Glossário: `GLOSSARY.md` na raiz.
- Decisões arquiteturais: `docs/adr/`.

Antes de explorar, leia o glossário e os ADRs pertinentes.
Se estiverem ausentes, prossiga; crie-os quando termos
ou decisões forem definidos.

Use o vocabulário do glossário em tickets, propostas e testes.
Sinalize lacunas de vocabulário para domain-modeling.
Explicite conflitos com ADRs, identificando a decisão
e o motivo de propor sua revisão.
